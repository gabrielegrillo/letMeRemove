# Choose your language

Quick starts are available in **English and Italian**. Each README covers
installation, offline demo, preview, daily use, keyboard controls and the effects
of leaving a team.

The CLI messages and detailed reference guides remain in English. PowerShell's
own prompts follow its language settings. A translated README does not change
the interface language.

Translations can be improved through a pull request; keep commands and safety
information equivalent across versions. AI-assisted translations need fluent
human review; see the [AI policy](../AI_POLICY.md).

| English | `en` | [English](../README.md) |
